## Nouveautés

- 🎰 **Invocations** : toutes les bannières du jeu, mises à jour automatiquement (sans réinstaller l'appli).
- **« Où mettre tes bookmarks ? »** : comparatif de rentabilité entre les bannières en cours.
- **Mise à jour automatique** : ZKX télécharge les nouvelles versions et les installe quand tu le fermes.

## Installer

Télécharge **ZKX-Setup-X.Y.Z.exe** ci-dessous et lance-le. Si Windows affiche « Windows a protégé votre ordinateur » : *Informations complémentaires* → *Exécuter quand même*.
