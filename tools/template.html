E7 · Overlay

L'appli ne lit pas le jeu et n'y touche pas. Pour l'import automatique, exporte ta box depuis l'optimiseur Fribbels (onglet Importer → Save), puis charge le fichier ici. Ta box et tes images restent dans ton navigateur. Pour mettre tes propres images de persos et d'artefacts, va dans l'onglet 📸 Mes captures. Sources : e7rtabot, Pocket Gamer, MMO Culture, Joytify, game.guide, TopUpLive, epic7db. Les partenaires, counters et builds détaillés existent pour les 30 meilleurs persos RTA ; pour les autres, l'appli se base sur leur tier.
